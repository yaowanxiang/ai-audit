# 多语言配置

## 支持语言

| 语言代码 | 语言名称 | 地区 | 完整度 |
|---------|---------|------|--------|
| zh-CN | 中文 | 中国 | 100% |
| en-US | 英语 | 美国 | 100% |
| ja-JP | 日语 | 日本 | 80% |
| ko-KR | 韩语 | 韩国 | 80% |
| fr-FR | 法语 | 法国 | 70% |
| de-DE | 德语 | 德国 | 70% |
| es-ES | 西班牙语 | 西班牙 | 60% |

## API使用

### 获取当前语言
```python
from ai_audit.i18n import get_language

lang = get_language()  # 'zh-CN', 'en-US', etc.
```

### 翻译消息
```python
from ai_audit.i18n import t

message = t('audit.start')  # 根据当前语言返回对应消息
```

### 切换语言
```python
from ai_audit.i18n import set_language

set_language('ja-JP')
```

### 生成多语言报告
```python
from ai_audit import Auditor

auditor = Auditor(rules=['hallucination', 'data-pollution'])
results = auditor.scan('path/to/code')

# 生成中文报告
report_zh = auditor.get_report(results, lang='zh-CN', format='html')

# 生成英文报告
report_en = auditor.get_report(results, lang='en-US', format='html')

# 生成日文报告
report_ja = auditor.get_report(results, lang='ja-JP', format='html')
```
