# AI Audit — Cross-Platform Build Plan
# AI代码认证 — 跨平台构建方案

> **Rule / 铁律**: Every user-facing tool MUST ship as a downloadable desktop installer.
> **原则**: 所有面向用户工具必须提供可下载安装的桌面客户端安装包。

## Overview / 概览

| Platform / 平台 | Installer / 安装包 | Format / 格式 | Builder / 构建工具 |
|----------------|-------------------|---------------|-------------------|
| Windows | `AI-Audit-Setup-<version>.exe` | NSIS installer / Inno Setup | PyInstaller + Inno Setup |
| macOS | `AI-Audit-<version>.dmg` | DMG disk image | PyInstaller + create-dmg |
| Linux | `AI-Audit-<version>.AppImage` | AppImage | PyInstaller + appimagetool |
| All / 全平台 | source run / 源码运行 | `python run_gui.py` | — |

## GUI Stack / 图形界面技术栈

- **Framework**: PySide6 (Qt 6) — mature, cross-platform, native look
- **Entry**: `run_gui.py` → `gui/main_window.py`
- **Features**: drag & drop folder, one-click scan, bilingual report, export JSON/HTML
- **Design**: fool-proof, 3-step flow (选文件夹 → 开始 → 看报告)

## Windows Build / Windows 构建

### 1. PyInstaller — 打包为 exe
```powershell
# 安装依赖 / Install deps
pip install pyside6 pyinstaller

# 打包 / Build
pyinstaller --noconfirm --windowed --name "AI Audit" `
  --add-data "gui;gui" `
  --icon build/windows/icon.ico `
  run_gui.py
```

### 2. Inno Setup — 生成安装包
```ini
; build/windows/installer.iss
[Setup]
AppName=AI Code Audit
AppVersion=0.3.0
DefaultDirName={autopf}\AI Audit
OutputDir=dist
OutputBaseFilename=AI-Audit-Setup-0.3.0
Compression=lzma2
SolidCompression=yes

[Files]
Source: "dist\AI Audit\*"; DestDir: "{app}"; Flags: recursesubdirs

[Icons]
Name: "{autoprograms}\AI Audit"; Filename: "{app}\AI Audit.exe"
Name: "{autodesktop}\AI Audit"; Filename: "{app}\AI Audit.exe"

[Run]
Filename: "{app}\AI Audit.exe"; Description: "Launch AI Audit"; Flags: nowait postinstall skipifsilent
```

### 3. 一键构建脚本 / One-click build
```powershell
# build/windows/build.ps1
$version = "0.3.0"
Write-Host "🔨 Building Windows installer v$version ..."
pyinstaller --noconfirm --windowed --name "AI Audit" run_gui.py
iscc build/windows/installer.iss
Write-Host "✅ Done: dist/AI-Audit-Setup-$version.exe"
```

## macOS Build / macOS 构建

### 1. PyInstaller — 打包为 .app
```bash
# 安装依赖 / Install deps
pip install pyside6 pyinstaller

# 打包 / Build
pyinstaller --noconfirm --windowed --name "AI Audit" \
  --add-data "gui:gui" \
  --icon build/macos/icon.icns \
  run_gui.py
```

### 2. create-dmg — 生成 dmg
```bash
# 安装工具 / Install tool
brew install create-dmg

# 生成 dmg / Create dmg
create-dmg \
  --volname "AI Audit" \
  --window-pos 200 120 \
  --window-size 600 400 \
  --icon-size 100 \
  --app-drop-link 480 250 \
  "dist/AI-Audit-0.3.0.dmg" \
  "dist/AI Audit.app"
```

### 3. 一键构建脚本 / One-click build
```bash
# build/macos/build.sh
VERSION="0.3.0"
echo "🔨 Building macOS dmg v$VERSION ..."
pyinstaller --noconfirm --windowed --name "AI Audit" run_gui.py
create-dmg --volname "AI Audit" "dist/AI-Audit-$VERSION.dmg" "dist/AI Audit.app"
echo "✅ Done: dist/AI-Audit-$VERSION.dmg"
```

## Linux Build / Linux 构建

### 1. PyInstaller — 打包为可执行文件
```bash
pip install pyside6 pyinstaller
pyinstaller --noconfirm --windowed --name "AI Audit" \
  --add-data "gui:gui" \
  run_gui.py
```

### 2. appimagetool — 生成 AppImage
```bash
# 下载工具 / Download tool
wget https://github.com/AppImage/appimagetool/releases/download/continuous/appimagetool-x86_64.AppImage
chmod +x appimagetool-x86_64.AppImage

# 创建 AppDir / Create AppDir
mkdir -p AppDir/usr/bin
cp -r "dist/AI Audit" AppDir/usr/bin/AI-Audit
cat > AppDir/AI-Audit.desktop <<EOF
[Desktop Entry]
Name=AI Audit
Exec=AI-Audit
Icon=ai-audit
Type=Application
Categories=Development;
EOF

# 生成 AppImage / Create AppImage
./appimagetool-x86_64.AppImage AppDir "dist/AI-Audit-0.3.0.AppImage"
```

## GitHub Actions — 跨平台自动构建 / Cross-platform CI

```yaml
# .github/workflows/build.yml
name: Build Installers

on:
  push:
    tags: ['v*']

jobs:
  build:
    strategy:
      matrix:
        os: [windows-latest, macos-latest, ubuntu-latest]
    runs-on: ${{ matrix.os }}
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: '3.11'
      - run: pip install pyside6 pyinstaller
      - name: Build with PyInstaller
        run: pyinstaller --noconfirm --windowed --name "AI Audit" run_gui.py
      - name: Create installer (Windows)
        if: runner.os == 'Windows'
        run: |
          iscc build/windows/installer.iss
          move dist/*.exe dist/AI-Audit-installer.exe
      - name: Create installer (macOS)
        if: runner.os == 'macOS'
        run: |
          brew install create-dmg
          create-dmg --volname "AI Audit" dist/AI-Audit.dmg "dist/AI Audit.app"
      - name: Create installer (Linux)
        if: runner.os == 'Linux'
        run: |
          wget https://github.com/AppImage/appimagetool/releases/download/continuous/appimagetool-x86_64.AppImage
          chmod +x appimagetool-x86_64.AppImage
          ./appimagetool-x86_64.AppImage AppDir dist/AI-Audit.AppImage
      - name: Upload artifacts
        uses: actions/upload-artifact@v4
        with:
          name: installer-${{ matrix.os }}
          path: dist/*.{exe,dmg,AppImage}
      - name: Attach to release
        uses: softprops/action-gh-release@v2
        if: startsWith(github.ref, 'refs/tags/')
        with:
          files: dist/*.{exe,dmg,AppImage}
```

## Download & Install / 下载与安装

### Windows
1. 下载 `AI-Audit-Setup-<version>.exe` / Download the exe
2. 双击运行，一路「下一步」/ Double-click, click Next
3. 桌面出现「AI Audit」图标 / Desktop shortcut created
4. 双击启动，拖入代码文件夹即可使用 / Launch, drag & drop folder

### macOS
1. 下载 `AI-Audit-<version>.dmg` / Download the dmg
2. 双击挂载，拖「AI Audit」到 Applications / Drag to Applications
3. 从启动台启动 / Launch from Launchpad

### Linux
1. 下载 `AI-Audit-<version>.AppImage` / Download the AppImage
2. `chmod +x AI-Audit-*.AppImage` 赋予执行权限 / Make executable
3. 双击运行 / Double-click to run
