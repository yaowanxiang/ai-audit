# AI代码审计 - 样例流水线

## 1. Python项目审计

```bash
# 初始化
ai-audit init

# 配置规则
cat > ai-audit-config.yml << EOF
rules:
  - hallucination
  - data-pollution
  - standard-mapping
languages:
  - python
  - javascript
standards:
  - GB/T
  - SLSA
  - EU-AI-Act
output:
  - html
  - md
  - sbom
EOF

# 扫描
ai-audit scan --config ai-audit-config.yml

# 生成报告
ai-audit report --format html --lang zh,en

# 导出SBOM
ai-audit sbom --format spdx --output sbom.spdx.json
```

## 2. 多语言项目审计

```bash
# 扫描多种语言
ai-audit scan \
  --lang python,javascript,java,cpp \
  --rules hallucination,data-pollution,standard-mapping \
  --output all-languages-report.html
```

## 3. 持续集成流水线

```bash
# 在CI中运行
ai-audit ci \
  --platform github \
  --token $GITHUB_TOKEN \
  --report-on-pr true \
  --fail-on high-risk
```

## 4. 规范映射示例

```bash
# 映射到SLSA
ai-audit map --input audit-result.json --to slsa --output slsa-report.json

# 映射到EU AI Act
ai-audit map --input audit-result.json --to eu-ai-act --output eu-report.json

# 生成双语对照表
ai-audit map-bilingual --input audit-result.json --output bilingual-table.md
```
