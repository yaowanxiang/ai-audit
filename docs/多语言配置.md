## 配置方法 / Configuration Methods

### 环境变量 / Environment Variables
```bash
export AI_AUDIT_LANG=zh-CN  # 中文
export AI_AUDIT_LANG=en-US  # English
export AI_AUDIT_LANG=ja-JP  # 日本語
export AI_AUDIT_LANG=ko-KR  # 한국어
```

### 命令行参数 / Command Line Arguments
```bash
ai-audit scan --lang zh-CN  # 中文
ai-audit scan --lang en-US  # English
ai-audit scan --lang ja-JP  # 日本語
ai-audit scan --lang ko-KR  # 한국어
```

### API调用 / API Calls
```python
from ai_audit import Auditor

# 中文 / Chinese
auditor = Auditor(lang='zh-CN')

# English
auditor = Auditor(lang='en-US')

# 日本語 / Japanese
auditor = Auditor(lang='ja-JP')

# 한국어 / Korean
auditor = Auditor(lang='ko-KR')
```

## 贡献翻译 / Contributing Translations

### 添加新语言 / Adding New Languages

1. 在 `locales/` 目录创建新文件 / Create new file in `locales/` directory:
   ```
   locales/[language_code].yaml
   ```

2. 复制英文模板 / Copy English template:
   ```bash
   cp locales/en-US.yaml locales/[language_code].yaml
   ```

3. 翻译所有字段 / Translate all fields

4. 提交PR / Submit PR:
   ```bash
   git checkout -b feature/add-[language]-translation
   git add locales/[language_code].yaml
   git commit -m "feat: add [language] translation"
   git push origin feature/add-[language]-translation
   ```
