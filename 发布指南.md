## 📋 发布步骤 / Release Steps

### 方式1: 使用GitHub CLI（推荐） / Method 1: Using GitHub CLI (Recommended)

#### 1. 登录GitHub / Login to GitHub
```bash
gh auth login
```
会打开浏览器授权，选择"Login with a web browser" /  
Opens browser for authorization, select "Login with a web browser"

#### 2. 创建仓库 / Create Repository
```bash
gh repo create ai-audit \
  --public \
  --description "AI code security certification framework: hallucination audit, data provenance, standard mapping (GB/T, SLSA, EU AI Act), 7-language support" \
  --homepage "https://ai-code-audit.org" \
  --source=. \
  --remote=origin \
  --push
```

#### 3. 创建Release / Create Release
```bash
gh release create v0.1.0 \
  --title "AI代码认证体系 v0.1.0 / AI Code Audit Framework v0.1.0" \
  --notes-file RELEASE_NOTES.md
```
